# Система проверки контрагентов и первичной документации (ООО «Валдэкс»)

ВКР бакалавра, 09.03.03 «Прикладная информатика». Django 5 + PostgreSQL + Bootstrap 5. Источники данных по умолчанию
работают в режиме `mock` (синтетические фикстуры), поэтому демо не требует интернета.

## Установка и запуск

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env                       # при необходимости поправьте значения
docker compose up -d db                    # PostgreSQL 15 (или свой сервер — см. POSTGRES_* в .env)
python manage.py migrate
python manage.py seed_demo                 # пользователи, 8 демо-контрагентов, история проверок
python manage.py runserver                 # http://127.0.0.1:8000
```

`seed_demo` работает только при `DEBUG=True` (в `config.settings.dev` так и есть) и безопасен для повторного запуска.
Bootstrap и Chart.js лежат в `static/vendor/`, CDN не используется.

## Демо-пользователи (только для разработки!)

Эти пароли публично известны: не создавайте такие записи на рабочем сервере. Для админки у пользователя должен быть
флаг `is_staff` (у `admin_demo` он стоит). Группы создаются миграцией `apps/core/0001_roles`; пользователь без группы
получает 403.

## Переменные окружения

См. `.env.example`: `DJANGO_SECRET_KEY`, `POSTGRES_*`, режимы источников `SOURCE_MODE_<ИСТОЧНИК>` (`mock` | `api` | `web`),
`EGRUL_API_KEY` (DaData, для режима `api`), переопределения весов скоринга `RISK_<КЛЮЧ>`. Секреты в репозиторий не кладутся.

## Текущая версия проекта

Автор: **Ильдар Салахетдинов**, Финансовый университет при Правительстве РФ.

- Семь источников: ЕГРЮЛ, «Прозрачный бизнес», реестр дисквалификации ФНС;
  ФССП, сообщения ЕФРСБ и арбитраж через API «Офдата»; перечень ЦБ о нелегальной финансовой деятельности.
- Демонстрационный и реальный режимы. Три источника ФНС работают без API-ключей;
  для «Офдата» нужен собственный `OFDATA_API_KEY`, расход ограничен локальной квотой.
- История проверок, роли, объяснимые факторы риска, PDF-отчёты и явная отметка неполноты сведений.
- Загрузка PDF/PNG/JPEG, OCR, подтверждение реквизитов и сверка подписанта.
- Отдельная CMS и встроенная PDF-подпись: OpenSSL, включая ГОСТ, проверка содержимого,
  цепочки сертификатов и отзыва при наличии доверенного набора.
- Перечень дополнительных документов в карточке и PDF, скачивание адресного запроса в TXT.
  Формирование запроса не отправляет письмо и не меняет оценку риска.
- Docker/Gunicorn/WhiteNoise, health endpoint, HTTPS за обратным прокси и резервное копирование.

## Проверки и ограничения

Полный прогон локальной версии от 08.11.2026: **375 тестов**, Ruff без замечаний.
Тогда же на VPS проверены ответы семи источников, OCR и электронные подписи.
Это датированные результаты; доступность внешних сервисов может меняться.
Ход работ: [PROGRESS.md](docs/PROGRESS.md).

Набор доверия проверен для цепочек Минцифры/Казначейства; поддержка всех УЦ не заявляется.
Криптографическая проверка не подтверждает сама по себе полномочия подписанта или МЧД.
Независимая валидация весов и измерение экономии труда остаются открытыми задачами.
Оценка ручной проверки отделена от хронометража: [экономический эффект](docs/economic_effect.md).
Перечень ЦБ в приложении не является полной шкалой ЗСК.
