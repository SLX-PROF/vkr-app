# Схема нормализованных данных источников

Каждый провайдер (`apps/scrapers`) возвращает `SourceResult(ok, data, error, elapsed, status)`.
`status` совпадает со значениями `SourceData.status`: `success`, `error`, `timeout`, `unavailable`.
В `data` лежит словарь с ключами, описанными ниже, независимо от режима (`mock` / `api` / `web`).
Если источник не вернул данные (`ok=False`), `data` пуст, причина — в `error`. Скоринг (этап 3) в этом случае
правило пропускает, а в отчёте помечает «Данные по <источником> получены не были».

Запрос во все источники — ИНН (строка). Даты — ISO `ГГГГ-ММ-ДД`, суммы — рубли (число).

## ЕГРЮЛ (`EGRUL`, класс `EgrulSource`)
| Ключ | Тип | Описание |
|---|---|---|
| `inn`, `ogrn` | str | Реквизиты |
| `full_name`, `short_name` | str | Наименования |
| `director_name`, `director_position` | str | Руководитель |
| `address` | str | Адрес регистрации (в режиме `web` пусто — в списке результатов адреса нет) |
| `registration_date` | str\|null | Дата регистрации |
| `status` | str | `active` / `liquidating` / `liquidated` / `bankrupt` |
| `okved_main` | str | Основной ОКВЭД (в режиме `web` пусто) |

## Прозрачный бизнес (`TRANSPARENT`)
| Ключ | Тип | Описание |
|---|---|---|
| `avg_headcount` | int | Среднесписочная численность |
| `revenue`, `taxes_paid` | number | Выручка, уплаченные налоги |
| `tax_regime` | str | Режим налогообложения |
| `has_tax_debt`, `tax_debt_amount` | bool, number | Недоимка по налогам: признак и сумма (правило срабатывает, если признак истинен или сумма > 0; +15) |
| `director_companies_count` | int | Сколько организаций у того же руководителя (массовый руководитель: > 5) |
| `address_companies_count` | int | Сколько организаций по тому же адресу (массовый адрес: > 10) |

## Дисквалифицированные лица (`DISQUALIFIED`)
| Ключ | Тип | Описание |
|---|---|---|
| `found` | bool | Руководитель найден в реестре |
| `person` | str | ФИО из реестра |
| `until` | str\|null | Дата окончания дисквалификации |

## ФССП (`FSSP`)
| Ключ | Тип | Описание |
|---|---|---|
| `active_proceedings` | int | Активные исполнительные производства (> 5 — штраф) |
| `total_debt` | number | Общая задолженность (порог 100 000 руб.) |

## ЕФРСБ (`EFRSB`)
| Ключ | Тип | Описание |
|---|---|---|
| `bankruptcy` | bool | Введена процедура банкротства |
| `procedure` | str\|null | Наблюдение / конкурсное производство и т. п. |
| `messages_count` | int | Число сообщений |

## КАД Арбитр (`KAD`)
| Ключ | Тип | Описание |
|---|---|---|
| `cases_last_year` | int | Дел за последний год (> 10 — штраф) |
| `as_defendant`, `as_plaintiff` | int | Роль в делах |
| `lost_cases_amount` | number | Сумма проигранных дел (порог «крупной» суммы определяется на этапе 3) |

## Режимы
`SOURCE_MODE_<KEY>` = `mock` (по умолчанию) | `api` | `web`.

| Источник | mock | api | web |
|---|---|---|---|
| ЕГРЮЛ | да | DaData по `EGRUL_API_KEY` | да, без обхода CAPTCHA |
| Остальные пять | да | не реализован (`unavailable`) | не реализован (`unavailable`) |

Дисквалифицированные лица: `api` не будет реализован (открытый набор ФНС не обновляется).

## Синтетические фикстуры
`tests/fixtures/<источник>/<ИНН>.json`, генератор — `scripts/make_fixtures.py`, перечень сценариев —
`tests/fixtures/demo_contractors.json`. Все ИНН/ОГРН начинаются с кода региона «00» (такого региона нет),
контрольные суммы верны.

| ИНН | Сценарий | Ожидаемый статус |
|---|---|---|
| 0000000018 | Чистая компания | safe |
| 0000000025 | Ликвидированная | dangerous |
| 0000000032 | Банкрот | dangerous |
| 0000000040 | Дисквалифицированный директор | risky |
| 0000000057 | Массовый адрес и руководитель | risky |
| 0000000064 | Много долгов ФССП | risky |
| 0000000071 | Много арбитражных дел | risky |
| 0000000089 | «Однодневка» (с недоимкой 480 000 руб.) | risky |
