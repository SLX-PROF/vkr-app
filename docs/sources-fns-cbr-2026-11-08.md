# Недостоверность ФНС и открытый перечень Банка России

Добавлены отдельные признаки недостоверности адреса и руководителя. Нормализация следует полям публичной карточки «Прозрачного бизнеса»: общий `vyp.invalid`, сообщения `НедСвАдресЮЛ[].ТекстНедАдресЮЛ` и `masruk[].invalid`. Поля `masrukinvalid` и массовость не интерпретируются как недостоверность конкретной организации. Общая положительная отметка без пояснения не приписывается адресу или руководителю. Пропущенные сведения остаются неизвестными. Версия кеша ПБ изменена, чтобы старые ответы не выдавались за новые.

Источник проверки соответствия полей: https://pb.nalog.ru/template.html?page=company (08.11.2026).

Седьмой провайдер использует открытый Warning list API Банка России. Поиск выполняется по ИНН; положительный результат принимается только после точного совпадения ИНН в DetailInfo. Записи без ИНН не связываются с проверяемым лицом. Отрицательный поиск не охватывает организации, опубликованные без ИНН, что указано в карточке и PDF.

Документация: https://www.cbr.ru/development/warning-list/ ; https://www.cbr.ru/warninglistapi/swagger . Прямая проба Search для 7703317501 08.11.2026 вернула HTTP 200 и пустой Data. Это не подтверждает отсутствие иных рисков компании.

ЗСК и отказы 764/639/550 не подключены. Собственный индекс, публичный перечень ЦБ и категория ЗСК показаны раздельно. Открытый сервис ЗСК сообщает о высоком риске, но не различает зелёную и жёлтую категории при отрицательном ответе. Документация стороннего API-ФНС описывает для zsk только значения 0/2, требует ключ; бесплатность этого метода не подтверждена. Источника жёлтой зоны и полной истории не установлено.

Источники: https://www.cbr.ru/counteraction_m_ter/platform_zsk/proverka-po-inn/ ; https://apifns.ru/api_help .

Дополнительные веса: адрес 30, руководитель 40, общий признак без детализации 30, совпадение ИНН в перечне ЦБ 70. Общий признак не начисляется повторно при конкретном. Это экспертные параметры, а не калиброванная вероятность. Для них по-прежнему требуется проверка на согласованной выборке.
