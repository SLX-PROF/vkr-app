# Расчёт экономического эффекта

Исходная оценка ручных трудозатрат получена от пользователя 08.11.2026:
проверка одного контрагента занимает 2–3 минуты на каждый источник.
Это оценка пользователя, а не результат хронометража.

При последовательной проверке шести источников расчётный диапазон составляет
12–18 минут на контрагента, семи источников — 14–21 минуту.
Седьмой источник расширяет объём проверки, поэтому для расчёта экономии
нужно сопоставлять одинаковый состав сведений до и после автоматизации.
Время подготовки итогового решения и запроса документов в эту оценку отдельно
не включается: пользователь не сообщал его продолжительность.

Фактические результаты внедрения и денежный эффект не установлены.

Параметры, которые заполняет автор по данным ООО «Валдэкс»:
- N — число проверок в месяц: <<ЗАПОЛНИТЬ>>.
- t0 — время текущей ограниченной проверки, минут: <<ЗАПОЛНИТЬ>>.
- t6 — расчётное время ручной проверки по шести источникам: 12–18 минут
  по оценке пользователя; хронометраж ещё не проведён.
- t1 — время работы сотрудника с ИС с учётом ручного разбора предупреждений: <<ЗАМЕР АВТОРА>>.
- r — стоимость часа сотрудника: <<ЗАПОЛНИТЬ>>.
- Cdev — затраты на разработку, обучение и внедрение: <<ЗАПОЛНИТЬ>>.
- Coper — эксплуатационные затраты в месяц, включая платные API: <<ЗАПОЛНИТЬ>>.

Экономия труда при сопоставимом объёме контроля: H = N × (t6 − t1) / 60 часов/месяц.
Денежный эффект: E = H × r − Coper.
Простой срок окупаемости: T = Cdev / E месяцев, только при E > 0.
Сравнение t0 и t1 отражает изменение затрат при расширении контроля и должно приводиться отдельно.
Предотвращённые убытки не включать в экономию без подтверждённых исходных данных.

Техническое время ответа приложения не равно времени работы сотрудника.
Для t1 нужно учитывать ввод ИНН, ожидание ответа, просмотр результата,
уточнение предупреждений и фиксацию решения. Ожидание ответа контрагента
учитывается отдельно как календарная длительность процесса.
Замер проверки подписи выписки ФНС около 0,7 с относится только к этой операции
и не используется как время полной проверки контрагента.
