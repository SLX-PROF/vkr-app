# Расчёт экономического эффекта

Это шаблон расчёта, фактические результаты внедрения не установлены.

Параметры, которые заполняет автор по данным ООО «Валдэкс»:
- N — число проверок в месяц: <<ЗАПОЛНИТЬ>>.
- t0 — время текущей ограниченной проверки, минут: <<ЗАПОЛНИТЬ>>.
- t6 — время полной ручной проверки по шести источникам, минут: <<ЗАМЕР АВТОРА>>.
- t1 — время работы сотрудника с ИС с учётом ручного разбора предупреждений: <<ЗАМЕР АВТОРА>>.
- r — стоимость часа сотрудника: <<ЗАПОЛНИТЬ>>.
- Cdev — затраты на разработку, обучение и внедрение: <<ЗАПОЛНИТЬ>>.
- Coper — эксплуатационные затраты в месяц, включая платные API: <<ЗАПОЛНИТЬ>>.

Экономия труда при сопоставимом объёме контроля: H = N × (t6 − t1) / 60 часов/месяц.
Денежный эффект: E = H × r − Coper.
Простой срок окупаемости: T = Cdev / E месяцев, только при E > 0.
Сравнение t0 и t1 отражает изменение затрат при расширении контроля и должно приводиться отдельно.
Предотвращённые убытки не включать в экономию без подтверждённых исходных данных.
