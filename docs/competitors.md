# Сравнение существующих решений

Данные взяты из публичных описаний разработчиков, просмотренных 08.11.2026.
Отсутствие функции на изученной странице не доказывает её отсутствия в продукте.
Цены не сравниваются: подходящий тариф и число пользователей организации пока неизвестны.

| Решение | Назначение и сильная сторона | Значение для этой разработки |
|---|---|---|
| Контур.Фокус | Анализ контрагентов, мониторинг, настраиваемые модели оценки, интеграционные возможности | Готовая альтернатива собственной проверке. Нельзя обосновывать разработку утверждением, что у Фокуса нет настройки правил |
| Saby Profile (СБИС) | Карточки компаний, связи, надёжность, события и мониторинг | Широкая аналитика; сравнивается с локальным сценарием ввода реквизитов строительных документов |
| Диадок | Электронный обмен, согласование и подписание документов, интеграция с учётной системой | Проверка личности подписанта в ЭДО шире простого сравнения строки ФИО. Разрабатываемая ИС не заменяет юридически значимый ЭДО |
| ЗАЧЕСТНЫЙБИЗНЕС | Портал сведений о компаниях и документированный API | Вариант подключения готовых данных вместо нескольких самостоятельных сборщиков; требуется согласование условий доступа |
| DaData «Организация по ИНН или ОГРН» | Узкая операция получения структурированных реквизитов через API | Подходит как поставщик данных ЕГРЮЛ; не заменяет весь сценарий проверки документа и архивирования |
| Сервисы ФНС | Прямой доступ к отдельным государственным реестрам | Можно использовать вручную или как источник в допустимых режимах. Сводный архив и собственный алгоритм остаются задачей ИС |

Собственная разработка обоснована учебной задачей, контролем над моделью данных и объединением
внутреннего сценария проверки контрагента и документа. Её экономическое преимущество перед
подпиской не доказано без расчёта разработки, поддержки и стоимости внешних данных.
