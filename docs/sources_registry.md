# Реестр открытых источников (предварительный, этап 2)

Пометка «требует проверки автором» — сведения не подтверждены первичным источником.

| Источник | URL | Что отдаёт | Формат | Интеграция | Ограничения и оговорки | Режим в проекте |
|---|---|---|---|---|---|---|
| ЕГРЮЛ (поиск ФНС) | egrul.nalog.ru | Наименование, ИНН, ОГРН, руководитель, дата регистрации, признак прекращения | JSON (два запроса: поиск → результат), PDF-выписка | web | При проверке один запрос прошёл без CAPTCHA; сайт может её потребовать — тогда «недоступен». Условия использования — требует проверки автором | mock (по умолчанию), web |
| ЕГРЮЛ через DaData | suggestions.dadata.ru | Те же данные + адрес, ОКВЭД, статус | JSON | api, ключ | Коммерческий сервис, бесплатный лимит 10 000 запросов/сутки (по документации DaData) | api (без ключа «недоступен») |
| ЕГРЮЛ, открытые данные ФНС | data.nalog.ru | Выгрузки по всему реестру | XML-архивы | не используется | Не поиск по ИНН; платный доступ — требует проверки автором | — |
| Прозрачный бизнес | pb.nalog.ru | Численность, налоги, недоимка, признаки массовости | HTML/JSON | web (не реализован) | Возможна CAPTCHA; в ответе «Валдэкс» — единственная практика проверки (недоимка) | mock |
| Дисквалифицированные лица | service.nalog.ru | Запись о дисквалификации | HTML | web (не реализован) | Открытый набор ФНС не обновляется → api не реализуется | mock |
| ФССП | fssp.gov.ru/iss/ip | Исполнительные производства | HTML + CAPTCHA | web (не реализован) | Защита от автоматических запросов, CAPTCHA не обходится | mock |
| ЕФРСБ (Федресурс) | bankrot.fedresurs.ru | Сообщения о банкротстве | HTML/JSON | api/web (не реализованы) | Условия использования — требует проверки автором | mock |
| КАД Арбитр | kad.arbitr.ru | Число и роли арбитражных дел | HTML (скрипты) | web, Playwright (не реализован) | Антибот; только сводная статистика | mock |

Общие правила для всех режимов `api` и `web`: таймаут 15 с, не более 1 запроса/сек на домен, кэш 24 ч (ИНН + источник),
честный User-Agent, журнал `logs/scrapers.log`, CAPTCHA не обходится.


## Проверка интеграций 08.11.2026

Реальные запросы к трём сервисам ФНС проверены локально и с рабочего VPS:

| Источник | Текущая реализация | Ограничения |
|---|---|---|
| ЕГРЮЛ | Публичный поиск, точный ИНН/ОГРН, реквизиты и руководитель | Для старых компаний дата присвоения ОГРН не равна дате создания; адрес/ОКВЭД дополняет PB |
| Прозрачный бизнес | Поиск юридического лица, показатели численности/выручки/недоимки, признаки массовости | Неизвестные значения остаются None; сведения разных лет не сопоставляются; доступны не все показатели |
| Дисквалифицированные лица | Поиск по текущему руководителю из ЕГРЮЛ; проверка периода и ИНН организации | Совпадение ФИО без достаточных идентификаторов требует ручной проверки |
| ФССП | Только mock; web недоступен | Проверенный прежний API возвращал HTTP 410; требуется ручная проверка |
| ЕФРСБ | Только mock; web недоступен | При пробном обращении ограничение доступа; автоматический обход не выполняется |
| КАД | Только mock; web недоступен | Автоматический поиск не реализован; требуется ручная проверка |

Это публичные веб-сервисы, а не гарантированный официальный API. При CAPTCHA/изменении формата
сервис фиксирует недоступность; отсутствие ответа не интерпретируется как отсутствие риска.
Кэш включает источник, режим и запрос, действует 24 часа в пределах рабочего процесса.
