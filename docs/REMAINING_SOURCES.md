# Дополнительные сведения: результаты поиска 08.11.2026

В схеме работающего Офдата v2 нет статуса окончания исполнительного производства, решения о текущей процедуре банкротства и результата рассмотрения иска с суммой проигрыша. Просмотр changelog не подтвердил появление этих полей. Документация новой платформы Чекко вернула 403; её наличие и возможности не объявлены подтверждёнными. Смена API не выполнялась.

Публичный ЗСК ЦБ по ИНН по-прежнему подтверждает только отнесение к высокой группе риска. Отрицательный результат не различает зелёную и жёлтую группы; источника полной истории не установлено. История собственных наблюдений системы не должна называться историей решений Банка России. Списки банковских отказов 764/639/550 не смешиваются с открытым Warning list API.

Источники: https://www.cbr.ru/counteraction_m_ter/platform_zsk/ ; https://www.cbr.ru/counteraction_m_ter/platform_zsk/proverka-po-inn/ ; https://ofdata.ru/api/changelog ; https://ofdata.ru/api/enforcements ; https://ofdata.ru/api/legal-cases .

Для подписи найден открытый проект GOST Engine для OpenSSL (https://github.com/gost-engine/engine). Его наличие не подтверждает работоспособность проверки конкретного файла, цепочки доверия, отзыва сертификата или квалифицированного статуса подписи. Следующий модуль требует уточнения формата входной подписи: отдельный .sig или встроенная PDF-подпись. Пользователю задан вопрос; ответ ещё не получен.

ФНС описывает бесплатную проверку МЧД по уникальному номеру в распределённом реестре: https://www.nalog.gov.ru/rn38/news/activities_fts/15371936/ ; адрес реестра https://m4d.nalog.gov.ru/emchd/ . Публикация архивная; при прямой проверке сервис ответил таймаутом. Работающий программный интерфейс проверки МЧД и проверка отзыва/набора полномочий пока не подтверждены. Нельзя заменять их одним совпадением ФИО с директором.
