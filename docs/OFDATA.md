# Бесплатное подключение дополнительных источников

Адаптеры `apps/scrapers/ofdata.py` используют документированный API «Офдата» v2:

- `enforcements`: опубликованные исполнительные производства;
- `legal-cases`: арбитраж за последний календарный год от даты проверки;
- `company`: опубликованные сообщения ЕФРСБ.

Документация: https://ofdata.ru/api/enforcements ; https://ofdata.ru/api/legal-cases ; https://ofdata.ru/api/company .
Тариф на https://ofdata.ru/api указывает бесплатный доступ для зарегистрированных пользователей до 100 запросов в сутки без финансовой отчётности. Доступность конкретных методов по новому ключу нужно проверить фактическим запросом. В документации рекомендована новая платформа «Чекко»; её ключ нельзя автоматически считать совместимым с API «Офдата» v2.

## Настройка

Добавить в закрытый `.env` переменную `OFDATA_API_KEY`. Не размещать ключ в чатах, Git или отчётах. Предел `OFDATA_DAILY_LIMIT` равен 90 по умолчанию, максимальное значение 100. API-запросы отправляются POST, ключ не включается в URL. Успешные ответы кешируются на 24 часа. На один источник допускается до трёх страниц по 100 записей. Более длинная выдача явно считается неполной.

Выбор «Реальная проверка» автоматически использует API для трёх дополнительных источников, если ключ задан. Демо не зависит от ключа. В сохранённом ответе указывается поставщик, а режим источника сохраняется как `api`. В карточке и PDF видны сводка, происхождение и до 30 записей каждого источника. Полный нормализованный ответ остаётся в SourceData.

Ограничитель учитывает локальные попытки и возвращаемый поставщиком `today_request_count`. Он не заменяет ограничения бесплатного тарифа в личном кабинете поставщика. При работе с ключом из нескольких приложений и при перезапуске процесса локальный счётчик не отражает все одновременные внешние запросы. Не включать платный тариф или пополнение баланса без решения пользователя. Для нескольких серверных процессов требуется общий кеш; текущее развёртывание использует один процесс Gunicorn.

## Что подтверждают результаты

**ФССП.** Поставщик предупреждает о нечётком поиске. Только точное совпадение опубликованного наименования и адреса с реквизитами выбранной компании допускается в подтверждённую сумму остатка долга. Остальные записи показываются как кандидаты. При неполноте сохраняется нижняя граница подтверждённого долга. Число активных производств не выводится из числа опубликованных записей: схема API не содержит признака окончания.

**ЕФРСБ.** Сохраняются тип, дата и номер дела опубликованного сообщения. Наличие исторического сообщения не устанавливает действующую процедуру банкротства, поэтому признак `bankruptcy` остаётся неизвестным. Для его подтверждения нужен актуальный судебный акт или иной структурированный источник текущей стадии. Отсутствующее поле ЕФРСБ не заменяется пустым списком.

**Арбитраж.** Проверяются точный ИНН участника и дата возбуждения в заданном периоде. Номер/UUID исключает повторный подсчёт. При ограничении страниц итоговый счётчик неизвестен, но показывается подтверждённое минимальное число дел. Цена иска не используется как сумма проигранных дел. По документации поставщика сведения могут задерживаться на 1–2 недели.

## Проверка прямых сайтов 08.11.2026

Публичная форма ФССП содержит вариант 5, поиск по ИНН юридического лица, с адресом `https://is-go.fssp.gov.ru/ajax_search`. Пробный запрос вернул HTTP 503 и сообщение о превышении лимита подключений. Федресурс вернул HTTP 401 со страницей CAPTCHA. КАД открылся в обычном Playwright без скрытия автоматизации; пользовательский поиск не дал выдачи, скрипт сайта завершился ошибкой `unreachable` при запуске WASM. Главная страница КАД не была засчитана как успешная проверка.

Защита сайтов, CAPTCHA и лимиты не обходились. Прокси для смены IP, подмена результатов и тестовый Федресурс вместо продуктивного не применялись.

## Оставшиеся условия

08.11.2026 ключ предоставлен пользователем и успешно проверен. Для ИНН 7703317501 все три метода вернули успешные ответы с пустыми списками записей. На VPS сохранён реальный сеанс № 9 с успешными ответами всех семи источников; новые три источника имеют режим api. Контрольные запросы с ИНН 7707049388 из примеров документации подтвердили непустую выдачу ФССП и арбитража (по 5 записей); схема записей соответствует адаптерам. Счётчик поставщика после этих запросов: 8 за день. Проверены вход по HTTPS, карточка, PDF из двух страниц и экран 390 px, ошибок HTTP/JavaScript нет.

Эти адаптеры не дают полную категорию/историю ЗСК или банковские списки отказов 764/639/550. Проверенный публичный ЗСК сообщает только об отнесении к высокой группе риска и требует CAPTCHA. Подтверждённого бесплатного источника жёлтой/зелёной категории и полной истории не найдено.
