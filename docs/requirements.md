## Согласованные ограничения
Ключей API нет. Для пяти источников api/web возвращают unavailable. Это предусмотрено текущим ТЗ;
приложение демонстрируется на синтетических данных. Внешние сведения не выдумываются.
ЕГРЮЛ web зависит от доступности публичного сервиса и не обходит CAPTCHA.
Данные о доверенностях, СРО, учредителях и криптографическая проверка подписи не реализованы.
Система проверяет выбранные введённые поля, а не все юридические условия действительности документа.
