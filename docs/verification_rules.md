# Правила сверки первичных документов (`apps/documents/verification.py`)

Серьёзность: **error** — документ нельзя принять без исправления; **warning** — нужна проверка человеком;
**info** — замечание, не влияющее на вывод «Соответствует».

| Код | Условие | Серьёзность | Основание |
|---|---|---|---|
| `NUMBER_MISSING` | не указан номер | error для счёта-фактуры и УПД; warning для остальных типов | НК РФ, ст. 169 (СФ/УПД); ФЗ-402 номер прямо не называет, но он нужен для идентификации (CLAUDE.md) |
| `DATE_MISSING` | не указана дата | error | ФЗ-402, ст. 9, ч. 2, п. 2 |
| `INN_MISSING` | не указан ИНН | error | идентификация контрагента |
| `INN_INVALID` | неверная длина или контрольная сумма ИНН | error | валидатор `apps/core/validators.py` |
| `AMOUNT_MISSING` | сумма не указана или равна нулю | error | ФЗ-402, ст. 9, ч. 2, п. 5 |
| `SIGNER_MISSING` | нет ФИО подписанта | error | ФЗ-402, ст. 9, ч. 2, п. 7 |
| `POSITION_MISSING` | нет должности подписанта | error | ФЗ-402, ст. 9, ч. 2, п. 6 |
| `EGRUL_UNAVAILABLE` | данные ЕГРЮЛ получить не удалось | warning | сверка ФИО и даты невозможна, остальные проверки выполнены |
| `NO_DIRECTOR_DATA` | в ЕГРЮЛ нет руководителя | warning | |
| `SIGNER_NOT_DIRECTOR` | ФИО подписанта не совпадает с руководителем | warning | напоминание проверить доверенность или приказ; данных о них в системе нет |
| `SIGNER_NAME_TYPO` | ФИО совпало неточно (опечатка) | info | |
| `DATE_BEFORE_REGISTRATION` | дата документа раньше даты регистрации контрагента | error | п. 5.3 ТЗ |

Остальные обязательные реквизиты ФЗ-402 (наименование документа, наименование экономического субъекта,
содержание факта хозяйственной жизни) в форме не вводятся и не проверяются: тип документа выбирается из списка.

**Сравнение ФИО.** Нормализация: регистр, «ё» → «е», пробелы и точки. Фамилия — первое слово длиннее одной буквы
(поддерживается «Образцов П.С.» и «П.С. Образцов»). Фамилия сравнивается нечётко (`difflib.SequenceMatcher`,
порог 0,85); имя и отчество — нечётко, если записаны полностью, и по первой букве, если хотя бы с одной стороны инициал.
Только фамилия без имени или инициалов не считается совпадением. Результаты: `exact` (совпадение), `typo`
(совпадение с замечанием `info`), `different` (предупреждение), нет данных.

**Вердикт** (`DocumentVerification.verdict`): `error` → «Есть расхождения», только warning → «Требует внимания»,
иначе «Соответствует» (замечания info допускаются).
