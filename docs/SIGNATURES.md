# Проверка электронной подписи

Реализованы отдельная CMS-подпись (.sig/.p7s) и встроенная подпись PDF
(adbe.pkcs7.detached, ETSI.CAdES.detached). OpenSSL проверяет хеш содержимого
и подписанные атрибуты. ГОСТ 2012 поддерживается бесплатным GOST Engine v3.0.5
с фиксированным коммитом исходников. Платный криптопровайдер не требуется.

Результаты разделены: целостность, доверие к цепочке сертификатов, отзыв.
Успешная проверка хеша не заменяет два остальных результата. При отсутствии
доверенного УЦ либо актуального CRL система сообщает о неполной проверке.
Проверка выполняется на текущее время; историческая действительность на дату
подписания без проверенной метки доверенного времени не устанавливается.
Это техническая проверка, без заявления о сертификации приложения как СКЗИ.

Для PDF контролируется ByteRange, исключение только Contents, соответствие
исключённого значения подписи и наличие дописанных после подписи данных.
Поддерживается BER с неопределённой длиной: именно такой формат обнаружен
в настоящей выписке ФНС. Нулевое заполнение отделяется без изменения CMS.

При успешной проверке содержимого извлекаются ФИО, ИНН организации и ОГРН
из сертификатов подписантов, выбранных OpenSSL. ФИО сверяется с реквизитами;
расхождение создаёт ошибку, неточное совпадение требует внимания.
Личный ИНН физлица не сравнивается с ИНН организации. Факт подписи сам по
себе не подтверждает полномочия представителя или действительность МЧД.

## Происхождение доверенного набора

08.11.2026 выписка по ИНН 7703317501 получена стандартным открытым протоколом
с https://egrul.nalog.ru/index.html через HTTPS с обычной проверкой TLS.
Хеш полученного PDF хранится в рабочем протоколе проекта; сам файл с данными
компании в публичный репозиторий не включается. Из CMS извлечена цепочка
Минцифры → Казначейство → подписант ФНС. Корень установлен при настройке
разработчиком из этого аутентифицированного государственного источника.
Загрузка произвольного пользовательского PDF корни доверия не меняет.

Корень Минцифры guc2022, SHA-256 DER:
`4bb37cc7c0ff4bf2aa893e95076ebb3565c69237ee1b61635beee4c1966495c7`.
Промежуточный Казначейства 2025, SHA-256 DER:
`999870011a6fd29fc6338af2c7dab496159e09377cdf2126ab3e604323afce21`.

Официальный перечень ресурсов:
https://www.nalog.gov.ru/rn77/related_activities/ucfns/ccenter_res/ .
Текущий набор включает CRL Минцифры и Казначейства. Он не означает
автоматической поддержки каждого аккредитованного УЦ России.

CRL загружаются только с фиксированных публичных адресов. HTTP здесь
защищается проверкой криптографической подписи самого CRL против заранее
установленного сертификата издателя; непроверенные корни по HTTP не
устанавливаются. Контролируются thisUpdate/nextUpdate и лимит 32 МБ.
Переходов по адресам из пользовательских сертификатов нет.

## Эксплуатация

`SIGNATURE_TRUST_BUNDLE=/app/trust/government.pem`.
Команда `python manage.py refresh_signature_trust` проверяет цепочку УЦ,
подпись и сроки обоих CRL и атомарно публикует PEM. Ошибка сохраняет
предыдущий набор; просроченный CRL затем не проходит проверку OpenSSL.
Соседний government.json содержит дату обновления, источники, сроки и хеши.
Сервис trust-refresh запускает обновление каждые шесть часов. Основному
приложению папка trust доступна только на чтение.

## Подтверждённые проверки 08.11.2026

- Настоящая подписанная выписка ФНС: целостность valid, trust verified,
  revocation verified, covers_current_file true.
- Учебные RSA и ГОСТ: верная подпись проходит, изменение содержимого
  отклоняется, данные после подписанной PDF-редакции обнаруживаются.
- Учебный УЦ и CRL: отзыв сертификата обнаруживается независимо от
  математически корректной подписи.
- Изменение байта подписи настоящего CRL отклонено; прежний набор сохранён.
- Веб-сценарий загрузки PDF, встроенной и отдельной ГОСТ-подписи выполнен
  через HTTPS; неправильная подпись меняет итог сверки на ошибку.
