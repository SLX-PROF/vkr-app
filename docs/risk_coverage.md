# Покрытие групп риска

| Группа | Источник и правило | Проверки |
|---|---|---|
| Налоговая задолженность | Прозрачный бизнес; tax_debt +15 | test_scoring.py: tax_debt_* |
| Подписант | ЕГРЮЛ; compare_names, предупреждение о доверенности | test_verification.py, test_final_workflow.py |
| Прекращение деятельности, массовость | ЕГРЮЛ liquidated +100 / liquidating +70; Прозрачный бизнес mass_director +20, mass_address +10 | test_scoring.py, test_run_check.py |
| Дисквалификация | DISQUALIFIED: disqualified +50 | test_scoring.py |
| Исполнительные производства | ФССП: debt_small +10 / debt_large +30, many_proceedings +20 | test_scoring.py |
| Банкротство и суды | ЕФРСБ bankruptcy +80; КАД many_cases +15, lost_large +25 | test_scoring.py |
| Малая численность при выручке | Прозрачный бизнес tiny_headcount +15 | test_scoring.py |

Отдельного правила недостоверности записи в ЕГРЮЛ пока нет: его нельзя заявлять как реализованное.
Внешние подключения пяти источников без ключей не реализованы; покрытие проверено на фикстурах.
Пустой/недоступный источник не означает отсутствия риска. Статус safe при частичной проверке
сопровождается явным предупреждением; решение остаётся за сотрудником.
